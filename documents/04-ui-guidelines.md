# 04. UI 규정

## 기본
- Jetpack Compose + **Material 3**. XML 레이아웃, 다른 UI 프레임워크를 쓰지 않는다.
- 색상, 타이포그래피, 간격은 **테마 토큰**(`MaterialTheme`, `Spacing` 등)만 사용한다. 하드코딩 금지.
- **다크 모드를 지원한다.** 동적 색상(Material You)은 선택 사항.
- 사용자에게 보이는 문자열은 모두 `strings.xml`에 둔다 (기본 한국어). 코드에 직접 쓰지 않는다.

## 화면 구성 (MVP)
| 화면 | 내용 |
|---|---|
| 로그인/가입 | Firebase Auth, 관심 분야 선택 |
| 홈 | 오늘의 맞춤 요약 목록 (카테고리 필터) |
| 요약 상세 | 요약문, 출처, 원문 링크, 오류 신고, (2차) 차트·TTS |
| 북마크 | 저장한 요약 |
| 설정 | 관심 분야, 발송 시간, 텔레그램 연동, Slack Webhook 연동(URL 입력·테스트 발송·해제), 다크 모드, 회원 탈퇴 |

## 필수 UI 규칙
1. **모든 요약 카드·상세에 다음을 표시한다**: 언론사명, 원문 링크 버튼, "AI가 요약함" 라벨.
2. 요약 상세에는 **오류 신고** 진입점을 둔다.
3. 모든 화면은 **로딩 / 빈 상태 / 오류(재시도 포함)** 상태를 구현한다.
4. 회원 탈퇴는 설정에서 접근 가능해야 하며 확인 절차를 거친다.
5. 위치 권한은 요청 전에 사용 목적을 설명하는 화면을 먼저 보여준다.

## Slack Webhook 연동 화면
- URL 입력 필드는 붙여넣기 후 형식(`https://hooks.slack.com/services/`)을 즉시 검증하고 오류를 보여준다.
- 저장 후에는 URL을 마지막 4자리만 마스킹해 표시한다. 전체 URL을 다시 보여주지 않는다.
- "테스트 발송" 결과(성공/실패 사유)를 표시하고, 서버가 채널을 비활성화한 경우 "재연동 필요" 상태와 안내를 보여준다.
- 연동 화면에 "채널 구성원 모두에게 요약이 보입니다" 문구를 표시한다.

## 컴포넌트
- 재사용 UI는 `ui/component/`에 둔다. 화면 전용 UI는 해당 화면 패키지에 둔다.
- Composable은 상태를 받고 이벤트를 올리는 **stateless**를 기본으로 한다.
- 모든 주요 Composable에 `@Preview`(라이트·다크)를 둔다.
- 리스트는 `LazyColumn`에 안정적인 `key`를 지정한다.

## 접근성
- 터치 영역은 최소 **48dp**.
- 아이콘·이미지에 `contentDescription`을 지정한다 (장식용은 `null`).
- 글자 크기(sp)를 사용하고 시스템 폰트 확대에서 레이아웃이 깨지지 않게 한다.
- 색만으로 정보를 구분하지 않는다. 대비는 WCAG AA 이상을 지킨다.
- **차트**는 색 외에 라벨·값을 함께 표시하고, 요약 텍스트 대안을 제공한다.

## TTS (2차)
- Android `TextToSpeech` 사용, 한국어(`Locale.KOREAN`). 재생/일시정지/정지, 속도 조절을 제공한다.
- 화면 이탈·앱 종료 시 반드시 `shutdown()`으로 자원을 해제한다.

## 차트 (2차)
- 서버가 이미지를 만들지 않고 **앱에서 수치 데이터로 직접 그린다** (Canvas 또는 승인된 차트 라이브러리).
- 기사 속 그래프를 복사하지 않는다. 수치를 구조화해 새로 그린다.
