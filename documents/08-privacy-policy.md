# 08. 개인정보 처리방침 (초안)

> 포트폴리오 앱용 초안이다. 법률 자문이 아니며, 실제 배포 전에 항목을 다시 확인한다. 앱 가입 화면과 설정 화면에서 이 내용을 요약해 보여준다.

## 1. 수집 항목과 목적
| 항목 | 목적 | 필수 |
|---|---|---|
| 이메일 또는 Firebase UID, 닉네임 | 회원 식별, 로그인 | 필수 |
| 관심 분야 | 맞춤 뉴스 요약 제공 | 필수 |
| 텔레그램 chat_id | 텔레그램 요약 발송 | 선택 |
| Slack Webhook URL | Slack 채널 요약 발송 | 선택 |
| 발송 시간, 알림 설정 | 발송 시각 지정 | 선택 |
| FCM 기기 토큰 | 앱 푸시 알림 | 선택 |

- 위치: 원본 위경도는 수집·저장하지 않는다. 기기에서 격자 좌표로 변환한 값만 날씨 조회에 쓴다.
- 관심 분야(정치 등)는 서비스 제공 목적으로만 쓰고 프로파일링·제3자 제공에 쓰지 않는다.

## 2. 보관과 파기
- 회원 탈퇴 시 모든 개인정보를 즉시 삭제한다 (hard delete, 관련 테이블 포함).
- 연동 해제 시 해당 chat_id·Webhook URL을 즉시 삭제한다.
- 발송 로그는 30일 후 삭제한다.
- chat_id와 Webhook URL은 암호화하여 저장한다.

## 3. 국외 이전·위탁
| 수탁자 | 위치 | 목적 |
|---|---|---|
| Google (Firebase Auth, FCM) | 해외 | 인증, 푸시 |
| LLM API 제공사 | 해외 | 기사 요약 (개인정보는 전송하지 않음) |
| Telegram | 해외 | 요약 발송 |
| Slack | 해외 | 요약 발송 |

## 4. 이용자 권리
- 언제든 열람·수정·연동 해제·탈퇴할 수 있다 (설정 화면).
- 문의처는 서비스 공개 전에 기재한다.

## 5. 변경
- 이 방침이 바뀌면 앱에서 고지한다.
